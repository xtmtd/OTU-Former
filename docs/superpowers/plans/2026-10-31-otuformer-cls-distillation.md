## Global Constraints

- New runs default to `--ssl-method relational`. The relational recipe is `0.12.0`'s — synchronized student/teacher pair, weak teacher views, center source, cross/full pairing and `0.08`–`0.11` teacher temperatures — not the pre-`0.12.0` batch-relative pairing this plan was written against. DINO is explicit; cross-method resume is rejected.
- D=`out_dim` defaults to 256; DINO K defaults to 64, K>=2. Existing iBOT K defaults to 512 and remains independent. D and K are not OTU counts.
- DINO uses the normalized 2048-hidden MLP, then a separate bias-free legacy-weight-normalized prototype layer. Canonical keys are `weight_g`/`weight_v`; scales stay one, have `requires_grad=False`, and are absent from the optimizer. No deepcopy of weight-normalized modules.
- EMA centering is default; optional SK uses exactly three iterations on both teacher globals together (N=2B), float32 stable normalization, no CLS EMA center. KoLeo weight defaults to 0, is finite/nonnegative and DINO-only.
- Global DINO pairs are A→B and B→A; locals use both teacher globals. Each component averages its own pairs. Total is `global + lambda_local*local + lambda_mask*patch_raw + koleo_weight*koleo_raw`, retaining defaults 1.5 and 1.0. No division by log(K).
- Student temperature remains 0.1; teacher temperature remains 0.04→0.07 over the first 70% of planned steps. Preserve existing LR/teacher EMA/extension rules.
- CLS and KoLeo use unmasked forwards. Existing extra masked forwards are patch-only. Reuse `PretrainForward.tokens[:, 0]` for pre-head backbone CLS; never add an image pass for KoLeo or prototypes.
- Freeze prototype direction only at absolute zero-based epoch 0, by clearing `.grad=None` after backward and before joint clipping/step. Keep one stable optimizer group containing encoder, student prototype direction and patch parameters.
- Source SSL identity, metric-head identity and invocation arguments are separate. `ssl_method`/`ssl_head` describe SSL payloads; fine-tune outputs use metric `embedding_head` plus SHA-anchored `ssl_source_*` lineage.
- In DINO, bypass legacy D-dimensional teacher center preprocessing/update; keep encoder centers zero/inactive. K-dimensional center state belongs only to the objective. Relational/patch center behavior remains unchanged.
- Default extraction is backbone CLS; DINO projector output is normalized D-dimensional bottleneck, never K logits. Read-only consumers do not construct training objectives.
- Preserve requested `Parameters:`/command replay and requested namespace fields. Effective SSL config travels separately and is resolved before output mutation. Inactive relational DINO config fields are omitted, while display nulls and existing patch nulls retain their own rules.
- No generic loss platform, DDP implementation, queue, cross-method initialization entry point, Coordinate implementation or real-data superiority gate.
- Keep external datasets read-only. Use synthetic images/tiny models/temp checkpoints; no real-data analysis. No dependency policy change, install, environment creation, commit or publication is implied by execution approval.

## Review Focus

Each condition has an owning test below, in addition to ordinary formula tests.

1. Repeated image records can yield coincident normalized CLS vectors: KoLeo remains finite, but its large positive contribution can dominate the total. Pin the epsilon-dependent magnitude and gradients in Task 2 and warn in Task 8; do not deduplicate records implicitly.
2. K much larger than 2B is valid, but logits/assignments grow with K×2B and prototype parameters with K×D. Test a moderate K≫2B shape in Task 2; Task 8 explains memory cost without claiming an arbitrary K is affordable.
3. SK under available CUDA/MPS execution may differ from CPU numerically: Task 2 adds device-conditional finite/detached/normalization checks and records unavailable devices, using float32 inputs/targets as in the current training loop; no mixed-precision path is introduced. CPU success alone is not accelerator validation.
4. A hybrid ref-script payload containing `model` plus SSL-looking tensors/metadata must retain metric/legacy classification or fail on contradictory active identity. Task 1 pins precedence and Task 7 preserves the existing fine-tune rejection; do not infer relational from width alone.
5. A two-crop batch can contain duplicate specimens even when B>=2: Task 4 verifies the actual per-crop pool and eligible counts without pooling crops or filtering records; Task 8 explains that eligible does not mean independent specimens.
